#Symbiosis Library Database Project

This project is a relational database designed for managing the operations of a library system. It was developed as part of my academic coursework during my database management studies. The dataset and requirements were provided by my professor to ensure adherence to specific learning objectives and to simulate a real-world library management scenario.

Features
* Comprehensive Library Management:
  * Tracks books, authors, members, loans, and due dates.
* Relational Design:
  * Uses structured relationships to model real-world library operations.
* Optimized Queries:
  * Includes SQL scripts for efficient data retrieval and manipulation.

Objectives
* Academic Learning:
  * Demonstrate understanding of relational database design and implementation.
  * Practice writing efficient SQL queries and constraints.
* Practical Application:
  * Simulate the operations of a library management system.
  * Build a foundation for creating scalable and robust database systems.

Learning Outcomes
* Database Design: Gained hands-on experience with designing normalized relational databases.
* SQL Proficiency: Developed skills in creating, populating, and querying databases.
* Problem-Solving: Simulated real-world scenarios to solve common database management challenges
---
Academic Context
This project was developed as part of the coursework for the Database Management Systems (DBMS) course at Symbiosis Institute of Technology. The primary goal was to apply theoretical knowledge to a practical, real-world system.
